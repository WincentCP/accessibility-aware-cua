# Frontend

- `research-console/` berisi template dan aset UI untuk sesi peserta serta empat
  mini-site benchmark.
- `extension/` berisi extension Chromium MV3 yang menghubungkan UI, panduan suara,
  turn-taking, dan agent tanpa menampilkan panel developer kepada peserta.

Frontend tidak boleh mengakses `benchmark/private/` atau menyimpan API key.
